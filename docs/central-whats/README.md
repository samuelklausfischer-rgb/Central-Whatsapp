# Documentação Central Whats

Pasta de handoff e continuidade do projeto.  
Serve para retomar contexto em outra janela ou sessão sem perder o histórico.

## Estrutura

| Arquivo | Assunto |
| --- | --- |
| `contexto.md` | Objetivo, stack e arquitetura |
| `historico.md` | Linha do tempo do que foi feito |
| `estado-atual.md` | O que está funcionando e pendências |
| `decisoes.md` | Decisões técnicas importantes |
| `problemas-conhecidos.md` | Bugs, riscos e como reproduzir |
| `proximos-passos.md` | Ordem para continuar sem perder contexto |

## Como usar

1. Ler `contexto.md` para entender o projeto.
2. Ler `estado-atual.md` para saber o que está pronto.
3. Ler `proximos-passos.md` para saber o que fazer a seguir.
4. Consultar `problemas-conhecidos.md` se aparecer algum erro.

## Observações

- Esta documentação é atualizada manualmente a cada sessão.
- Arquivos em português, seguindo o padrão do projeto.
- Manter sempre `proximos-passos.md` com o próximo passo clairo.
